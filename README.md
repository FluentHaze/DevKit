# DevKit

本地优先的开发者网页工具箱。把接口排查、数据转换、编码、文本处理和前端素材处理放在一个工作台中，输入内容在浏览器内处理，无需登录。

当前代码版本 **0.1.0**，包含 **7 类、49 个工具入口**。文档核对日期：2026-10-29。功能已实现不等于完成全部浏览器与无障碍发布验收，详见[验证记录](docs/verification.md)。

## 快速开始

需要 Node.js **22.12+**（`.nvmrc` 使用 Node 24）和 pnpm **8.10+**（项目固定使用 pnpm 8.10.5）。

```sh
pnpm install --frozen-lockfile
pnpm dev
```

打开终端给出的地址，默认是 `http://127.0.0.1:5173`。安装前可用 `nvm use` 切换 Node 版本；没有 nvm 时直接安装符合要求的 Node 即可。开发服务器绑定本机回环地址。

```sh
pnpm build
pnpm preview
```

`build` 先进行 TypeScript 检查，再输出 `dist/`，为每个工具生成静态入口和离线资源。`preview` 用于本机查看生产构建，不表示已部署线上。

| 编码与加密   |    7 | Base64、URL/Unicode/HTML 编解码、哈希、AES、HMAC、JWT 解析                   |
| 时间与日期   |    4 | 时间戳、时区、日期计算、Cron                                                 |
| 代码与文本   |    9 | 代码/Markdown 格式化、压缩、混淆、文本对比、正则、批处理、环境配置、编码转换 |
| CSS 与视觉   |   10 | 颜色、渐变、阴影、圆角、Flex/Grid、单位、动画、SVG、图片处理                 |
| URL 与接口   |    5 | URL 解析/对比、cURL 转代码、参数转换、HAR 分析、HTTP 速查                    |
| 生成器与数值 |    4 | UUID/随机字符串、进制转换、测试数据、二维码                                  |

完整的 **49 项功能、参数默认值、输入输出、使用注解、限制和代码位置**见[工具手册](docs/tools.md)。入口及分类以 `src/tools/metadata.json` 为准；新增工具后需同步这张表和功能手册。

## 如何使用

1. 通过分类或搜索进入工具，粘贴文本、选择本地文件，或先载入示例。
2. 调整参数，点击“运行”。部分简单转换和 CSS 预览会自动更新。
3. 查看结果，再复制或下载。修改输入会使旧结果失效，避免复制过期输出。
4. 大任务可取消。清空移除内容；重置同时恢复参数，敏感工具的重置不可撤销。

| 操作         | Windows / Linux   | macOS             |
| ------------ | ----------------- | ----------------- |
| 全局搜索     | Ctrl + K          | ⌘ + K             |
| 运行当前工具 | Ctrl + Enter      | ⌘ + Enter         |
| 搜索结果导航 | ↑ / ↓、Enter、Esc | ↑ / ↓、Enter、Esc |

侧栏、首页和运行按钮的快捷键提示随平台切换。支持简体中文 / English、浅色 / 深色 / 跟随系统、收藏排序、最近使用和响应式布局；切换语言保留机器结果。顶栏语言入口带语言图标和当前语言，自动模式也显示实际语言；所有下拉框使用统一的自定义圆角菜单，支持键盘和触屏操作。

## 数据、文件与离线

- 输入、源代码、文件、密钥和 Token 不上传；生成的请求代码只作为文本展示，不执行请求。工具不会自动打开二维码识别出的地址。
- 普通工具只有主动开启“保存草稿”才会持久化输入与参数，上限为序列化字符串的 256 Ki 个字符。刷新默认丢弃未保存内容；站内会话草稿保存在内存中。
- AES、HMAC、JWT、cURL、请求参数、HAR、环境配置、文本编码和二维码禁止持久草稿。读取本地文件会关闭并清除对应工具的持久草稿；文件引用切页后需重新选择。
- 文本与普通文本文件上限 5 MiB，哈希文件上限 100 MiB；图片上限 20 MiB / 3200 万像素，SVG 输入上限 512 KiB。其他条数与格式限制见工具手册。
- 首次加载资源需要联网。**生产构建**中可在设置下载完整离线资源；开发服务器不提供生产离线缓存功能。缓存完成后才能依赖离线使用，更新需用户选择刷新。
- Web Crypto、Clipboard、Service Worker 等能力依赖安全上下文，通常需要 HTTPS 或 localhost。能力缺失会报错或提供手动复制方式。

注：JWT 解析不验签；Schema 根据示例推断；图片输出为静态帧；GBK 等源编码手动选择；cURL 脱敏按常见字段名识别，分享前仍需核对。详细边界请查对应工具说明。

## 项目与检查

React 19、TypeScript 5、Vite 8、Tailwind CSS 4；使用本地 JSON 翻译资源、原生 textarea 编辑器、Web Worker 和按需加载的算法依赖。没有引入后端、运行时 CDN 或遥测。

```sh
pnpm docs:check
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

`pnpm format` 会格式化整个项目，日常修改应仅格式化相关文件。换行由 `.gitattributes` 统一为 LF；最近检查及尚未覆盖的验收项见[验证记录](docs/verification.md)。依赖用途、许可证和来源见[依赖说明](docs/dependencies.md)。

部署前阅读[开发与文档维护流程](docs/development.md)。现有 Pages 工作流使用 `/DevKit/` 构建路径；根域名部署使用默认 `/`。本地构建通过不代表远程工作流或线上行为已经验证。
