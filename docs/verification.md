## 复查命令

```sh
pnpm docs:check
pnpm typecheck
pnpm lint
pnpm format:check
pnpm test
pnpm build
```

专项性能可执行 `pnpm test src/tools/performance.test.ts`。报告通过环境变量 `DEVKIT_BENCHMARK_REPORT` 指定可写 JSON 路径，仅记录环境与耗时，不含用户内容。历史样例不包括文件读取、浏览器渲染和 Worker 启动，不能作为跨设备承诺。
