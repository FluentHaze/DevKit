# 界面设计规范

更新：2026-10-29。规范依据当前组件和 `src/styles/index.css`；[概念图](design/devkit-web-concept.png)仅是早期视觉参考，不能作为真实功能或数据截图。

## 视觉方向

清晰层级、克制色彩、细边框和适量留白的网页生产力工具。沿用网页导航，不添加操作系统窗口按钮、Dock、设备外壳或 Apple 标志。视觉风格不决定平台按键：Windows / Linux 显示 Ctrl，macOS 显示 ⌘。

首页突出搜索、收藏、最近使用和分类，不添加挤占工具入口的营销区。优先复用 `Button`、`Editor`、`Select` 和主题 tokens，不为每个工具另造控件体系。

## 布局与响应式

| 宽度       | 当前布局                                                      |
| ---------- | ------------------------------------------------------------- |
| < 768px    | 顶栏菜单触发抽屉，主区 16px 内边距，输入输出堆叠              |
| 768–1199px | 64px 图标导航栏，主区 24px 内边距；约 900px 起编辑器可双列    |
| >= 1200px  | 240px 完整导航，顶栏约 56px；大屏主区随断点增加到 32px 内边距 |

当前桌面分栏通过滑块调节 35%–65%，不是拖拽分隔条。文件图片 / 二维码识别没有文本输入时，结果区域单列；不显示无效分栏控件。编辑器最小高度约 400px，长页面自然滚动，不固定全页高度裁切内容。

工具页基本顺序：面包屑 → 标题/说明/收藏 → 动作栏 → 参数和可视配置 → 注解及文件状态 → 预览/输入输出 → 辅助输入 → 处理状态/导出 → 相关工具。具体工具可按输入类型省略不适用部分。

## 字体与图标

- UI 使用系统字体栈：-apple-system / BlinkMacSystemFont / Segoe UI / PingFang SC / Microsoft YaHei / sans-serif；不远程加载字体。
- 代码使用 ui-monospace / SFMono-Regular / Menlo / Consolas / monospace。
- 常规标题约 24px、正文 14px、参数/按钮 13px、说明 12px；长英文不裁切关键信息，容器 min-width 允许缩小。
- 图标为 Lucide SVG；独立图标按钮必须有名称，装饰图标避免重复朗读。品牌名、代码与结果不翻译。

## 组件规则

### 参数控件

文本和选择器采用“标签在上，控件在下”，常规最小高度 36px；参数网格默认 1 列、sm 2 列、xl 4 列，多行配置跨列。

**复选框使用单独的横向布局**：左侧 16px 方框、右侧文字，整行 label 可点击，保留原生键盘行为；边框容器与相邻输入框底部对齐，最小高度 36px。禁止把复选框继续套成“标题上方、孤立方框下方”。长文字允许换行，方框不缩小。

### 自定义下拉选择

所有选择器统一使用 `components/Select.tsx`，包括语言、设置主题、工具参数、AES 密钥位数和 Grid 子项；不展示系统原生 select 弹出菜单。采用克制的 Apple 风格：8px 触发框、12px 圆角浮层、细边框、柔和阴影与轻量背景模糊，跟随浅深色 tokens。

悬停仅轻微改变背景；选中项采用 accent-subtle 和勾选标记。键盘聚焦使用 focus-visible 环，不将鼠标 hover / 点击焦点做成内外两套蓝框。浮层不改变页面布局，视口边缘自动避让，空间不足向上展开，长列表内部滚动；父滚动容器不能裁切菜单。

语言入口在顶栏带语言图标，宽屏显示“语言 / Language”和当前语言，窄屏保留图标和当前语言；自动状态也显示实际解析语言，如“简体中文 · 自动”，菜单选项为简体中文 / English / 跟随浏览器。不能只用一个“自动”让新用户猜用途。窄屏顶栏省略重复面包屑，保留下面工具页的完整路径和标题。

### 动作与编辑器

- 一个操作组最多一个主要动作；运行中显示处理中与取消，避免重复提交。
- 输出标题栏提供复制和下载，明确区分文本结果、图片下载和指定编码文件下载。
- 编辑器提供行号、可选换行、实际 UTF-8 字节/行/码点统计；不可用导出操作为 disabled。
- 状态采用图标加文字，说明限制或警告，不只靠颜色传达错误。
- 底部最多三个同类相关工具入口；不遮挡主要工作区。

### 预览

CSS 使用受限 iframe；动画提供暂停与重置。SVG 和二维码用图片预览，Markdown 清理后放入不允许脚本的 iframe。预览不访问用户输入的外部地址；清理导致的外观差异需注解提示。

## 验收目标

检查 1440×900、1024×768、390×844 的浅深色和中英文；页面不横向溢出，代码长行在编辑器内滚动。键盘焦点可见；当前基础 focus-visible 为 2px、3px 偏移。常规目标至少 24×24px，主要触屏操作尽量扩大到 44px；完整 WCAG 目标与未验项见[验证记录](verification.md)。

尊重 prefers-reduced-motion，减少非必要过渡，动画预览默认暂停。修改共享控件后检查其他调用方，并同步[交互规范](interaction-style.md)及验证记录。
