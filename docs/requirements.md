# 产品范围与验收目标

更新：2026-10-29。当前版本 0.1.0，**10 类、91 个入口已实现，完整发布验收仍待补齐**。本文件定义范围和完成标准；现有功能参数见[工具手册](tools.md)，执行证据见[验证记录](verification.md)。

## 产品目标

让开发者通过“搜索工具 → 输入或选择文件 → 设置参数 → 查看结果 → 复制或下载”完成日常任务，减少站点切换，并让业务数据在本地浏览器内处理。

目标为现代桌面浏览器，兼顾移动端基础使用。支持 zh-CN / en 双语、系统主题、收藏、最近使用和可选普通草稿。当前不提供账号、云同步、后端请求代理、远程代码执行或收费流程。

## 通用能力与边界

### 输入、任务和结果

- 文本工具提供正常结果、空态、错误、示例、清空、重置、复制及适用的下载；生成器和只读速查按自身流程展示。
- 通过任务 ID 和中止机制避免过期结果写回；正则 1 秒超时，普通执行任务 60 秒超时；批量工作台 120 秒、正则重命名 5 秒、Markdown 实时预览 10 秒，SVG / 二维码识别有独立可终止 Worker。
- 机器结果不随语言变化。UI 字节统计默认是 UTF-8，不应当作 GBK 文件字节数；编码工具另提供编码后的实际字节数。
- 上限由代码执行：普通输入/辅助输入 5 MiB，哈希文件 100 MiB，图片 20 MiB / 3200 万像素，SVG 512 KiB；各工具还有条数和复杂度限制。

### 隐私与存储

- 输入不进入 URL；转换和文件处理不上传、不遥测，生成代码不执行。WebSocket 仅主动连接/发送后向指定服务器通信。离线资源缓存只存站点资源，不存用户输入。
- 普通草稿需要主动开启，当前实现按序列化字符串长度限制为 256 × 1024 个字符。收藏和最近使用只存稳定 ID，最近使用最多 20 条。
- 禁止持久草稿的工具以 `src/lib/sensitive-tools.ts` 为唯一代码定义，包含敏感文本工具与全部文件/媒体工作台，不在此复制易过期的完整清单。
- 文件读取关闭并清除当前工具的持久草稿；文件引用不跨工具页面保留。站内内存草稿与持久草稿不同，不能混为“刷新后仍可恢复”。

### 多语言与平台

- 语言优先级：已保存手动偏好 → 浏览器支持语言 → zh-CN。zh 系列映射 zh-CN，en 系列映射 en；其他语言不新增未翻译选项。
- 翻译标题、说明、控件、状态和 aria 标签；不翻译用户输入、代码、URL、字段名或算法标识。
- 切换语言保留输入、参数、结果；URL 不带语言前缀。系统快捷键提示 Windows / Linux 为 Ctrl，macOS 为 ⌘；搜索与运行分别使用 K / Enter。

### 离线与部署

- 首次联网加载不等于可完整离线；生产构建的设置提供“下载离线资源”和清除入口，缓存成功后再验证断网流程。
- 新工具路由和本地依赖必须进入构建清单。不得将远程 CDN、字体或在线 API 当作离线依赖。
- 静态路由刷新需要可用。现有构建生成各工具静态目录、404 壳和 Service Worker，不依赖 SPA rewrite。
- 根路径与子路径托管都要校验。默认 `/`，Pages 工作流配置 `/DevKit/`；构建成功不等同线上验证。

## 明确不承诺的能力

| 工具或场景        | 当前边界                                                                                                  |
| ----------------- | --------------------------------------------------------------------------------------------------------- |
| cURL              | 支持常用 POSIX / CMD / PowerShell 字面参数；不执行 shell、文件上传、动态展开或任意 flag；重复 header 拒绝 |
| JWT               | 解析 Header / Payload 和声明时间，未验签，不判断 Token 是否可信                                           |
| JSONPath          | 安全子集；不执行脚本过滤，不宣称完整 RFC 9535                                                             |
| JSON Schema / Zod | 根据样本推断；不推断未出现字段、业务范围或正则约束                                                        |
| 多语言资源检查    | 常见命名 / printf 占位符；不支持完整 ICU MessageFormat                                                    |
| 图片              | 输出静态帧，剥离原始元数据；不保证每张图都比源文件更小                                                    |
| 文本编码          | 源编码手动选择，不自动猜测；目标无法表示的字符报错                                                        |
| SVG / Markdown    | 清理与隔离预览，不执行脚本或加载外部资源；SVG 清理可能改变外观                                            |
| 浏览器与可访问性  | 当前及上一主版本的 Chrome / Edge / Firefox / Safari、WCAG 2.2 AA 是目标，未完成全矩阵认证                 |

## 功能交付标准

单个工具的“完成”至少包含实现、双语、正常/空/错误/边界处理、导出、隐私、相关验证和同步文档。纯只读速查页不要求执行转换或导出。

发布验收还需确认：所有路由、完整语言/主题/视口矩阵、键盘与辅助技术、复制失败、文件读取和取消、离线更新与配额、网络审计、目标浏览器版本。初始 JS gzip ≤ 250 KB 是性能目标；输入量和设备不同，不把单次耗时样例写成普遍性能承诺。

新增或深化能力时遵循[文档同步流程](development.md)，同时更新功能手册、相关规范和验证记录。

TypeScript → JSON 示例支持 interface/type、本地引用和常见对象结构，使用固定示例值；不执行代码，不保证完整 TypeScript 类型系统兼容，边界见工具手册。
