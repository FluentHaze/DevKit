# 交互风格规范

## 1. 操作原则

让输入、参数和结果的对应关系清晰。即时反馈不抢焦点，处理失败保留输入，耗时任务可取消。默认不弹确认框；仅在将丢弃未保存内容或批量清理本地数据时确认。

## 2. 搜索与导航

- ⌘/Ctrl+K 打开全局搜索；↑↓选择、Enter 打开、Esc 关闭，关闭后焦点回原位置。
- 搜索无结果时显示关键词及建议；不要生成不存在的工具入口。
- 独立路由可直接访问，刷新可恢复页面；未知路由提供回首页和工具搜索。
- 收藏按钮即时切换，提供可访问状态；拖拽排序同时提供键盘“上移/下移”。最近使用仅记录访问的工具。
- 站内切换默认保留本次会话输入；刷新不恢复敏感内容。关闭提醒仅在用户显式编辑且有未导出结果时使用，遵循浏览器能力限制。

## 3. 输入与处理模式

- 简单转换（如 Base64、时间戳）默认防抖 250ms 自动处理；输入法组合期间不运行。
- 昂贵或显式动作（加解密、文件哈希、混淆、大文本）由“运行”触发；CSS 参数调整实时预览。
- ⌘/Ctrl+Enter 运行当前工具；不得覆盖编辑器必要快捷键。⌘/Ctrl+K 只在产品层占用。
- 空输入显示操作提示，不报语法错误；格式化工具空输入不生成虚构对象。
- 粘贴示例若会替换现有编辑内容，提供确认或可撤销替换；不自动读取剪贴板。
- 修改输入或影响结果的参数后，旧结果标为“待更新”；新结果完成前不能误复制旧结果。长任务用任务 ID 防止乱序写回。
- 重置恢复当前工具默认参数、清除输入输出和临时文件引用；有内容时提供一次撤销。敏感工具不保留可撤销的密钥副本，按钮说明此限制。

## 4. 状态模型

| 状态      | 界面和行为                                                               |
| --------- | ------------------------------------------------------------------------ |
| idle      | 显示示例入口、输入提示；输出为空。                                       |
| dirty     | 输入已更新，结果待更新；显式运行工具显示运行按钮可用。                   |
| running   | 按钮显示处理中，耗时任务提供取消；不能重复提交同一任务。                 |
| success   | 显示结果、实际统计与可用操作。                                           |
| error     | 保留输入；显示原因、字段或行列与修正建议；不将旧输出呈现为当前成功结果。 |
| cancelled | 显示已取消，可重试；不覆盖当前输入。                                     |

## 5. 复制、下载与错误

- 复制只复制目标内容，不包含行号、状态和说明；成功显示短提示约 2 秒，避免弹窗。
- Clipboard 不可用时选中文本并提示手动复制；失败不能显示成功。
- 下载使用工具名、时间和扩展名；文件内容与当前结果一致。取消或过期结果不可下载。
- 错误分为输入错误、参数错误、浏览器能力缺失、执行失败；使用具体措辞，如“IV 需要 16 字节，当前为 12 字节”。
- 字段错误通过 aria-describedby 关联；处理完成提示使用 aria-live=polite，不在每个键入时重复朗读。
- 提供“清空”与“重置”的一致区分：清空只移除内容，重置同时恢复参数。

## 6. 特殊工具行为

- JSON 对比联动滚动可关闭；忽略选项变化后重新计算，不隐藏真实类型变化。
- JSON 多层解码显示当前层、上一步和下一层；到普通文本停止，设置最大 10 层防止意外循环。
- 日期输入始终显示来源时区与输出时区；自动推断单位附可见标签和手动覆盖入口。
- AES 加密默认生成新随机 IV，每次运行不复用默认 IV；解密必须填写原 IV。复制结果提供完整结构化包，避免丢失算法参数。
- JWT 显示“未验签”；过期信息只表示对声明值的时间判断。
- 正则超时后终止 Worker，并提示缩小文本或修改表达式；不能无限等待。
- CSS 数字控件允许手输与滑块；键盘可调，保留有效中间输入；预览与代码使用同一份状态生成，复制包含必要选择器。
- CSS 预览使用隔离容器/受限 iframe；只允许约定 CSS 属性与结构，不执行用户脚本，不加载用户提供的外部资源。动画可随时暂停。

## 7. 隐私与离线

“本地处理”表示当前工具内容不离开浏览器，不意味着首次打开无需网络。工具缺少离线资源时显示“首次使用需要联网加载”，缓存完成后再显示可离线使用。

设置可管理收藏、主题、普通工具草稿和离线缓存；按类型清除，批量清除前说明影响。敏感字段不保存、不加入搜索记录、不进入错误上报或分享链接。

## 8. 语言切换

第一版支持简体中文与 English。顶栏或窄屏设置中的语言菜单可键盘操作，标明当前选择。手动选择保存本地，可在设置恢复自动检测；语言切换不刷新页面、不运行工具、不清空或翻译输入输出、不更改时区。菜单关闭后焦点回触发按钮，提示按新语言显示。正在执行的任务保持执行，结束后的状态以当前语言显示。搜索接受中英文关键词并以当前语言呈现结果，切换不重置收藏与最近使用。
