# 交互与状态规范

更新：2026-10-29。以下说明通用工具页面的当前行为和后续变更应保持的操作约定。具体工具的特殊格式、上限和不支持项见[工具手册](tools.md)。

## 导航、搜索与平台提示

| 操作         | Windows / Linux 提示 | macOS 提示 |
| ------------ | -------------------- | ---------- |
| 全局搜索     | Ctrl + K             | ⌘ + K      |
| 运行当前工具 | Ctrl + Enter         | ⌘ + Enter  |

侧栏、首页、运行按钮共用 `lib/keyboard.ts` 的平台判断。现有按键处理兼容 ctrlKey / metaKey，不能仅改图标而让实际操作失效。

全局搜索支持中英文别名、↑↓选择、Enter 打开、Esc 关闭，关闭搜索还原焦点。独立工具路由可直接访问，未知路由提供返回入口。收藏即时切换并有选中状态，排序同时保留键盘上移/下移；最近使用仅记录 ID 与时间，最多 20 条。

## 输入、示例和参数

- 粘贴文本不自动读取剪贴板；文件由用户选择。示例会覆盖已有输入或文件时确认，示例不代表真实业务数据。
- 文本参数有可见标签；复选框为“左框右文”的整行 label，点击文字与按空格均可切换。修改参数后旧结果失效，不能复制过期结果。
- 自动处理工具：Base64、URL 编解码、时间戳、字符串转换、CSS 单位以及 `visualTools` 集合中的 CSS 工具。防抖约 250ms，输入法组合期间跳过处理。
- 其他工具通过运行按钮或快捷键触发。输入为空时通常显示 idle 提示；无文本生成器仍可运行，图片/二维码识别未选文件时提示缺少文件。
- `.env`、HAR、cURL 等结果可能含敏感内容；默认隐藏值或按模式脱敏不能取代用户分享前核对。

## 下拉选择的统一交互

全项目选择器使用自定义 combobox / listbox，不调用系统原生选项菜单；原 JSX option 仅作为声明数据，不渲染成原生 select。所有调用方使用 `value` / `onValueChange(value)`，不会伪造 DOM change 事件。

- 点击触发框展开，点击选项提交后关闭；点击外部关闭，不夺取新目标焦点。
- 方向键打开 / 移动，Home / End 到首尾，Enter / 空格选择，Esc 关闭并保留触发框焦点；Tab 关闭并按正常顺序离开，不困住键盘。
- 支持短时间内输入首字母或前缀定位；禁用项不能选择。长选项可换行，长列表内部滚动，不触发全页横向溢出。
- 选中值与键盘高亮分开；仅移动高亮不应运行转换，提交新值后才更新参数。选择当前值不重复触发任务。
- 浮层随视口和锚点变化重定位；普通页面挂载到 body，模态设置框内挂载到对应 dialog，避免被顶层遮住。卸载时清理事件和尺寸观察。
- 触发框提供可访问名称、展开状态和当前值说明，列表使用 option / aria-selected。完整辅助技术认证仍属于待验项目。

## 任务与状态

| 状态      | 界面与操作                                         |
| --------- | -------------------------------------------------- |
| idle      | 等待输入或示例，输出为空                           |
| dirty     | 输入/参数变动，旧结果清除，等待处理                |
| running   | 运行按钮禁用并显示处理中，允许取消                 |
| success   | 显示结果、耗时和可用导出                           |
| error     | 保留输入，显示本地化错误摘要，不把旧结果显示为成功 |
| cancelled | 显示取消，不接收被中止任务的后续结果               |

普通执行上限 60 秒，正则 1 秒；媒体 Worker 有独立中止和超时。输入修改、取消、超时或卸载都应停止旧任务；不能只隐藏 spinner 但仍允许旧 Promise 覆盖新状态。

当前通用错误展示在页面状态区，以 role=status / aria-live=polite 提示。JSON 行列详情可跳转源编辑器；并非所有工具都有每个字段的行内错误或 aria-describedby。以后新增字段级错误时才相应记录该能力。

## 清空、重置、撤销与切页

- **清空**移除输入/辅助输入、文件和结果，保留当前参数。
- **重置**恢复当前工具默认参数并清除输入输出和文件；普通工具保存一次撤销，敏感工具不提供重置撤销，避免保留额外秘密副本。
- 工具切换保留内存中的输入、参数和结果；当前 File 引用不跨页保留，文件处理需重选。刷新不恢复未主动保存的文本，也不恢复敏感工具内容。
- 已编辑、处理成功且未导出的结果可能触发浏览器关闭提醒；没有成功结果时不保证提示，不能把提醒当作自动保存。

## 复制与下载

复制只取机器结果，不包括行号或注解。成功反馈约 2 秒；Clipboard 失败时选中结果并提示手动复制，不能显示虚假成功。

文本下载使用当前结果的扩展名。图片工具的“下载图片”导出实际图片字节；编码工具的“下载编码文件”使用目标编码，复制文本仍是 Unicode。Base64 等工具可额外下载原始字节。文件名包含工具 ID 与时间，不包含用户秘密或源文件名。

导出只对 success 状态开放。取消、修改参数或新输入后，不允许导出旧成功结果。

## 预览与专用行为

- JSON 对比可关闭联动滚动，按身份匹配数组时忽略对象重排但不隐藏字段变化；身份缺失或重复明确报错。
- JSON 反转义可逐层继续，最多 10 层；不自动无限解码。
- AES 每次加密生成随机 IV，解密使用包内 IV 或显式填写的原 IV；JWT 始终标记未验签。
- 日期显示来源/目标或推断单位；来源时区、编码和机器结果不随 UI 语言改变。
- SVG 先清理再优化，清理可能改变外观；Markdown 只清理预览，复制仍保留格式化 Markdown 文本。
- 图片与二维码读取支持本地生成示例，不申请摄像头、不自动访问识别内容；图片输出是静态帧。
- CSS 预览隔离站点样式，禁止脚本与网络；动画可暂停/重置，减少动态效果时默认暂停。

## 隐私、语言和离线

持久草稿需主动开启，敏感集合见 `lib/sensitive-tools.ts`；所有文件读取先关闭并清除对应草稿。清理收藏、最近使用、草稿和缓存按类型执行，批量清理先确认影响。

语言在顶栏通过图标和明确文字入口选择简体中文 / English / 跟随浏览器；自动状态同时显示实际语言。手动选择存储本地，改回跟随浏览器恢复自动检测。切换不刷新、不执行转换、不清空输入、不翻译机器结果；任务完成后的状态使用当前语言。

“本地处理”不表示首次打开可断网。生产设置下载全量资源后才能完整离线；缺资源或能力失败应显示真实状态。新版本由用户确认刷新，不能在后台强制刷新丢失输入。离线缓存不存用户输入。

## 修改后的核对

检查输入—参数—结果对应关系，以及空/错误/取消、文字点击与键盘、长文案、浅深色、语言切换、文件与导出。共享交互变动同步[设计规范](design-style.md)、[开发流程](development.md)和[验证记录](verification.md)。

## 文件、媒体与实时工具

批量工作台提供文件清单、参数、示例、运行/取消、清空/重置、状态、预览和下载；运行快捷键仍随系统显示 Ctrl/⌘。修改输入后旧下载不可用，文件引用不跨页面保留。表格支持直接编辑单元格及 JSON；像素画支持键盘点击网格；图片标注既可编辑 JSON，也可点击预览定位。抽签转盘遵循减少动态效果偏好，实际结果来自 Worker 内的 Web Crypto 抽取。

Markdown 输入停止 350ms 后更新清理预览；打印使用浏览器对话框保存 PDF。WebSocket 显示连接/断开状态，仅主动操作时联网；不能在浏览器自定义握手 Headers。批量重命名默认预览，开启导出后才生成副本 ZIP。音视频格式由浏览器本地解码能力决定，失败显示错误。

时间工作台的倒计时面板每秒刷新、可暂停，导出为运行时快照。分账在非零余额 ≤12 人时搜索最少转账笔数，大群组使用贪心算法，页面说明该边界。
